=== STEP 0 (UI, before editing the script) ===
In Agent Builder, add the two new Apex actions to the Client Meeting Summary subagent: "Find Client" (FindClientAction)
and "Answer Client Question" (MeetingPrepService). That creates their definitions under the subagent-level "actions:"
block. This patch assumes Agent Builder names them Find_Client and Answer_Client_Question; if it uses other names,
use those names in BLOCK 4 (both before the colon and after "@actions.").
Output API names (not labels): Find Client -> selectedAccountId (label "Selected Client Id"), message, matchesText,
clients, totalMatches, success. Answer Client Question -> answer, sources, reviewItems, message, status, success.

             11. For any question about a client (open deals, what was last discussed, who attended, research), never answer from earlier conversation or from another action's output.
